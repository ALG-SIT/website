# CSS改善の次段階プラン

## 目的

完了済みのCSS配置整理を再実施せず、全ページの表示差を確認したうえで、今後の変更が表示とLCPに与える影響を小さな単位で判断できる状態にする。Tailwind CSS v4は短く単純なユーティリティに使い、複雑な再利用スタイルはAstroコンポーネントのスコープ付きCSS、記事本文は`content.css`に置く。vanilla-extractへの移行は現時点では行わない。

## 現状

- `global.css`は245行、`content.css`は311行。ページ固有・コンポーネント固有の規則は各`.astro`へ分離済み。
- 基準版との5回交互LCP中央値はトップ+1ms、記事-1ms、プロジェクト-77msで、定めた許容幅内。
- 初回HTML+CSS gzipはページによって増減する一方、トップ→記事→プロジェクトのキャッシュ後再訪合計は約10.7KB減少。
- 既存の表示検証は全ルート・全ビューポートの画像比較を網羅していない。今回の次段階ではまず表示差の全体像を確定する。

## 実施フェーズ

### 1. 比較対象と条件を固定する

1. 基準はCSS整理前のコミット`57d8ccb`、比較対象は現在の作業ツリーとする。
2. 基準版・比較版をそれぞれ同じ方法でビルドし、生成物、フォント、画像、ブラウザバージョンを記録する。
3. 全12ルート、幅320/375/768/1023/1440px、ライト／ダークの組み合わせを比較する。
4. フォントと画像の読み込み後に同じChromium条件で撮影し、ページ高・横はみ出し・主要要素の位置とスクリーンショット差を記録する。
5. 内容や意図したデザイン変更を含む箇所は、差分を回帰と混同しないよう一覧化する。

### 2. 表示差を分類して必要箇所だけ修正する

1. 差が大きいページ・画面幅を優先し、基準／現行の画像と主要要素の寸法を目視確認する。
2. 差分を「意図した変更」「フォント・画像等の環境差」「意図しないレイアウト差」に分類する。
3. 意図しない差があれば、該当ページまたはコンポーネントだけを直す。全体セレクターの追加や`!important`で覆わない。
4. 修正した画面条件で再撮影し、差が解消したことを確認する。

### 3. LCPの再現性を確認する

1. トップ、記事詳細、プロジェクト詳細を代表ページとして、同一のローカル配信条件でベースラインと現行版を交互に各5回以上測定する。
2. 各回の値、中央値、ばらつき、LCP対象要素、ネットワーク／キャッシュ条件を保存する。
3. トップだけが悪化して見える場合、まず計測ばらつきとLCP対象要素・画像読み込み・フォント適用時刻を確認し、CSS変更に起因すると判断できる証拠が揃ってから修正する。
4. 初回HTML+CSS gzip、キャッシュ後のCSS転送量、LCPを別々に記録し、単一指標だけで方式を切り替えない。

### 4. 今後のスタイル変更を小分けに運用する

1. 変更前に対象コンポーネント／ページ、見た目の期待値、代表画面、性能指標を記録する。
2. 一つのコンポーネントまたは関連する一つのページ群ずつ変更する。
3. 各段階でlint、型検査、build、生成物検証、E2Eを実行し、影響した画面の視覚比較を行う。
4. 合格後に次の群へ進む。差分が説明できない、または性能ゲートを超えた場合は次段階に進まず原因を切り分ける。
5. Tailwindクラスは短く単純な単発スタイルに限定する。長い任意値、状態・ブレークポイントが複雑な表現、重複パターンは意味のあるCSSクラスまたはコンポーネントへ置く。

## 合格条件

- 12ルート×5幅×2テーマの全120条件で撮影・比較が完了し、差分を分類できる。
- 全条件で意図しない横スクロール、クリッピング、重なり、操作不能がない。
- トップ・記事・プロジェクトのLCP中央値が、基準版に対して100msまたは5%の大きい方を超えて悪化しない。
- HTML+CSSの初回転送量とキャッシュ後転送量を両方報告し、増加分の理由を説明できる。
- lint、型検査、build、生成物検証、E2Eが成功する。

## vanilla-extractの再検討条件

現行のAstroスコープ付きCSSを維持する。将来、実際に複数ページで共有する複雑なスタイルが増えた場合に限り、代表ページ3つ以上で方式を比較する。見た目と機能が同等で、HTML+ロードCSS gzip合計が5%以上減り、LCP基準も満たす場合に再評価する。行数削減だけを理由に導入しない。

## 成果物

- 120条件の比較結果、差分画像、ページ高・横はみ出しの一覧。
- LCP測定の各回値、中央値、ばらつきと測定条件。
- 意図した差分／環境差／修正対象の分類記録。
- 必要な場合のみ行った局所修正と、その再検証結果。
