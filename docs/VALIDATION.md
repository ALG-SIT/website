## 自動検証

- 固定インストール：`bun ci`
- Biomeによるlint・整形・import順とMDX補助検査：`bun run lint`
- 型検査：`bun run check`（エラー・警告・ヒントなし）
- 公開ポリシー：`bun test`（4件）
- 本番生成：`bun run build`（18ページ、検索対象5ページ）
- コンテンツ統合：`bun run test:content`（不正値・参照・slug、下書き・将来記事の配信除外、MDX、公開ゲート、コンテンツ0件）
- ブラウザ：`bun run test:e2e`（12件）

ブラウザでは375・768・1280px、ライト・ダークモード、WCAG AAの自動検査、日本語検索と検索失敗からの再試行、フォーカス復帰、カテゴリー切り替え、テーマ保存、ストレージ無効時、メニュー、目次、コードコピー、JavaScript無効時、404を確認しました。

下書き記事・将来記事・下書きプロジェクトの固有文字列を、検索インデックスを含む全配信ファイルから検査しています。不正コンテンツのテストは一時ディレクトリで実行し、作業ファイルを変更しません。

Wrangler 4.153.0を固定依存に追加し、ローカルのWorkers Static Assets配信で次を確認しました。10月25日の記録に加え、配信設定を検証した結果です。

- `bun ci`：ロックファイルによる固定インストール成功。
- `bun run lint`：Biome・MDX検査成功。
- `bun run check`：エラー・警告・ヒントなし。
- `bun test`：8件成功。ブランチ変数の未設定・空白拒否、mainの公開検証維持、プレビューでの公開検証無効化、子プロセスの終了コード伝播を確認。
- `bun run build`：20ページ生成、7ページを検索インデックス化、成果物検証成功。
- `bun run test:content`：不正コンテンツ・下書き除外・正式公開ゲート・空コンテンツに加え、Workersのmainで検索許可、機能ブランチで検索拒否を確認。プレビューでは`SITE_RELEASE=1`が渡されてもビルド成功。
