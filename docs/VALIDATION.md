# 実装時の検証記録

2026年10月25日、ローカルの本番相当ビルドで確認しました。Cloudflare・GitHub・DNSの実環境設定と独自ドメインでの公開確認は未実施です。

## 自動検証

- 固定インストール：`bun ci`
- Markdown・整形：`bun run lint`
- 型検査：`bun run check`（エラー・警告・ヒントなし）
- 公開ポリシー：`bun test`（4件）
- 本番生成：`bun run build`（18ページ、検索対象5ページ）
- コンテンツ統合：`bun run test:content`（不正値・参照・slug、下書き・将来記事の配信除外、MDX、公開ゲート、コンテンツ0件）
- ブラウザ：`bun run test:e2e`（12件）

ブラウザでは375・768・1280px、ライト・ダークモード、WCAG AAの自動検査、日本語検索と検索失敗からの再試行、フォーカス復帰、カテゴリー切り替え、テーマ保存、ストレージ無効時、メニュー、目次、コードコピー、JavaScript無効時、404を確認しました。

下書き記事・将来記事・下書きプロジェクトの固有文字列を、検索インデックスを含む全配信ファイルから検査しています。不正コンテンツのテストは一時ディレクトリで実行し、作業ファイルを変更しません。

開発プレビューはnoindexとrobotsによる登録拒否があるため、SEOは66〜69です。正式公開時にこれらを解除し、公開URLで90以上を再確認してください。測定レポートは無視対象の`artifacts/lighthouse/`に保存します。

INPと実ユーザーのCore Web Vitalsは未測定です。自動検査はWCAG適合性の完全な保証ではないため、公開前に実端末とキーボードでも最終確認してください。

## 公開前の残作業

- サンプルを正式コンテンツへ差し替え、掲載許可・連絡先・入部情報を確認する。
- 実在するCODEOWNERS、保護ルール、GitHubとPagesの連携を設定する。
- Pages環境変数、DNS、証明書、リダイレクトを設定する。
- PRプレビュー、mainからの自動公開、ビルド失敗時の正常版維持、ロールバックを実環境で確認する。
